Notes:
- `OfferConversionClassification` maps to `offers.offerModel` (BIGSERIAL-keyed, varchar(20), default 'rfq'). Canonical business name: offerModel.
- `OfferContractClassification` is a distinct logical concept (partner_marketplace / logimarket_reseller / external_redirect). NO_CURRENT_ELEMENT.
- `offers.conversionType` (varchar(20), default 'outbound') is a parallel field requiring further audit.
- `Offer` is an external reference pointing to the existing offers table (BIGSERIAL PK).
- `OfferMarketplaceClassification` is a new aggregate root in SELLER_AND_OFFER_CLASSIFICATION that owns offer-level classification elements.
- `SellerProfile` does NOT own offer classification elements.
